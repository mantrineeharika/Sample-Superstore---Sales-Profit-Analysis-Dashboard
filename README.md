# 📊 Sample Superstore – Sales & Profit Analysis Dashboard (Power BI)

## 🔍 Project Overview
This project focuses on analyzing the **Sample Superstore** dataset using **Power BI** to uncover meaningful insights related to **sales**, **profit**, **customer segments**, **regions**, and **product categories**.  
The dashboard provides a complete view of business performance through interactive visuals and KPIs, helping stakeholders make informed decisions.

---

## 🎯 Objectives
- Analyze overall **Sales & Profit Performance**.
- Identify **top- and bottom-performing categories** and regions.
- Understand the **impact of discounts** on profit.
- Visualize **customer segment behavior** and purchase trends.
- Build an interactive & user-friendly **Power BI dashboard** for business insights.

---

## 📂 Dataset
- Dataset: *Sample Superstore*  
- Contains fields such as:
  - Order Date, Ship Date  
  - Region, State, City  
  - Category & Sub-Category  
  - Customer Segment  
  - Sales, Quantity, Discount, Profit  

---

## 🛠️ Tools & Technologies Used
- **Power BI Desktop**
- **Power Query** (Data Cleaning & Transformations)
- **DAX** (Calculated Columns & Measures)
- **Data Modeling**
- **Interactive Visualizations**

---

## 📐 Approach
1. **Data Import & Cleaning**
   - Removed missing values  
   - Standardized data types  
   - Performed required transformations using Power Query  

2. **Data Modeling**
   - Created relationships  
   - Added calculated columns & DAX measures for Sales, Profit KPIs  

3. **Dashboard Design**
   - Designed with clear layout and clean formatting  
   - Added visuals: bar charts, line charts, donut charts, KPI cards, maps  

4. **Analysis**
   - Sales & profit trends  
   - Category, region, and segment performance  
   - Discount versus profit impact  

---

## 📊 Key Insights
- Certain regions and categories show **strong profit margins**, while others suffer due to high discounting.  
- **Technology** category frequently leads in total sales.  
- **Consumer and Corporate segments** contribute a major portion of revenue.  
- Some products become **loss-making** when discounts increase beyond threshold.
